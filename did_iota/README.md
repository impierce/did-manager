# did_iota

Using [identity.rs](https://github.com/iotaledger/identity.rs) to resolve and publish DID documents.

> [!IMPORTANT]
> In the current version, only DIDs are supported that are _already published successfully_ to the network.
> Full token management would be necessary to provide the tokens for the storage deposit.
> This is already in progress, but requires some more time to properly address the complexity.
